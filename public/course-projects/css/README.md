# CSS student planner
Open index.html in a browser. No installation or server is required.

Keep this as a practice copy, or bring styles into the multi-page HTML project.

## Your tasks
- Create your own palette and spacing tokens; check actual contrast pairs.
- Add a third card and explain the grid placement.
- Make navigation wrap with long link text.
- Review 320px, tablet, desktop, 200% zoom, keyboard focus, and reduced motion.
- Keep page-wide horizontal overflow absent; test the schedule's local scrolling.
- Preserve visible labels, meaningful headings, and source order.
- Write down two decisions and one issue you fixed. Make meaningful Git commits.

## Honest limits
This is a static learning project. Input changes are temporary; no task is stored
or submitted. The disabled button is labelled accordingly. Project work is
self-reviewed, not automatically graded by Init.
